# Iconos de MEETIX Transcriber

Coloca aquí los PNG del icono en las siguientes medidas (con fondo transparente recomendado):

- meetix-16.png (16x16)
- meetix-32.png (32x32)
- meetix-48.png (48x48)
- meetix-128.png (128x128)

Opcional: también puedes añadir 64x64 y 256x256 si quieres.

Sugerencias:
- Usa la ilustración proporcionada y exporta versiones cuadradas centradas.
- Evita texto excesivo en 16x16; prioriza el pictograma (cámara + hoja).
- Mantén el contraste alto para el modo oscuro/claro de Chrome.

Una vez añadidos, recarga la extensión en `chrome://extensions` (botón "Actualizar").
